## Общая приёмка и runtime

Объединённый integration HEAD ещё не закреплён. Обязательные следующие проверки: два synthetic аккаунта проходят register/login/logout/revoke/friends/direct/self/group/reply/edit/delete/pin, failed send/draft, minimized unread, reload/reconnect; четыре малых file/image/audio/video проходят actual ciphertext upload/finalization/download/decrypt/use. Mobile actual surface проверяется на 320/390/768 CSS px, portrait/landscape, 200% desktop zoom и keyboard/focus; baseline ширина composer textarea не ниже 140 CSS px, history скроллится отдельно.

Пользователь подтвердил доступ только к текущей Mac-сессии. Реальные два устройства/слышимость/NAT/forced TURN/Wi-Fi↔cellular и iOS/Android OS keyboard остаются UNVERIFIED. Browser emulation, synthetic PC/audio/capture и DOM geometry не заменяют эти пункты. После полного #176 нужен отдельный three-client actual SFU/admission/revocation/media matrix; предупреждение о доступе SFU к аудио обязательно.

Единственный runtime owner — delivery/runtime. Основной owned compose project `aerochat-remediation-20261011`, профиль `~/.local/state/agent-dev/aerochat-remediation-20261011/fixture.env`; ports/volumes/credentials managed вне Git. Feature-native schemas и S3 UUID keys изолированы; special recovery/readiness projects остановлены в finally без удаления retained volumes. Общий runtime ещё не подтверждает все draft fixes: перед rebuild/cutover нужны quiet source freeze, backup/restore prerequisites и новые receipts. Чужие stacks/volumes/cache не меняются; production/SSH/load/публичное scanning не выполнялись.

После общей приёмки появятся 90–120s honest demo script, 4–6 актуальных screenshots и README с implemented/validated/deferred. Текущие screenshots README — исходный audit fixture. Full E2EE/MLS/key backup/history/offline и отсутствие всех bugs не заявляются.
